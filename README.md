# Skills for myself

Personal reusable skills for article research and writing.

| Skill | Purpose |
| --- | --- |
| [GPI thought leadership](gpi-thought-leadership/SKILL.md) | Evidence-led, brand-specific articles with Fable 5.1 through OpenRouter, source-image discovery, branded visuals, and measured cost controls. |
| [Research listicle](research-listicle/SKILL.md) | Sourced agency, company, service, and tool listicles with Tavily research, OpenRouter workers, and research/editorial gates. |

Each folder includes its instructions, references, and any helper scripts. These are copies of the personal skills; changes here do not automatically update an installed copy.

## Install

Copy the desired folder into your Codex skills directory, normally `~/.codex/skills/`. Preserve an existing installation before replacing it.

Invoke with:

```text
Use $gpi-thought-leadership for [brand] on [topic].
Use $research-listicle to write [listicle topic].
```

Read the selected skill and its tool reference for prerequisites, model routing, and credential configuration. Credentials are not included. Some examples refer to Dave's local installation paths; adjust them for another machine.

The thought-leadership skill's article cost target has not yet been benchmarked. Both workflows require actual source verification and distinguish measured costs from estimates or unknown charges.
